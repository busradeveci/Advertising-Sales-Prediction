## Advertising Sales Prediction

This project builds a linear regression model to predict sales based on advertising budgets for TV, Radio, and Newspaper using the Advertising Dataset from Kaggle.

## 📌 Overview

The goal is to predict sales by analyzing the impact of advertising expenditures. Key steps include:

### 🔍 Data Exploration
Visualized correlations to understand how ad budgets affect sales.

### 🧠 Model Training
Built a linear regression model using scikit-learn.

### 📊 Evaluation
Measured performance with R² score and Mean Squared Error (MSE).

### 📈 Findings
TV advertising has the most significant impact on sales.
